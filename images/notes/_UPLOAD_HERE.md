# UPLOAD HERE: images for Expository Notes

Figures and diagrams used in notes go here (PNG, JPG, SVG).

In a note, include one with:

```
![Short description of the figure](../../../images/notes/my-figure.png)
```

(The `../../../` climbs from `notes/articles/<note-name>/` to the site root.
A figure used by only one note can instead sit next to that note's `index.qmd`.)
