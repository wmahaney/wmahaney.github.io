# UPLOAD HERE: talk slides

Put the slides of talks you have given here, as PDF files.

**Naming.** `year-meeting.pdf`, in lowercase, with hyphens and no spaces:

```
2025-mason-vii.pdf
2025-ams-southeast.pdf
2024-pants-xxxvii.pdf
```

If you gave two talks at one meeting, add a word from the title: `2025-mason-vii-isogenies.pdf`.

**Linking.** Open `research/talks.yml`, find the talk, and put the file name between the
quotes of its `slides:` line:

```
  slides: "2025-mason-vii.pdf"
```

A "Slides" link then appears next to that talk on the Research page. A talk whose
`slides:` is empty shows no link.
